# DSH UI Enhancements

DSH UI 增强套件 - 三合一插件，包含：

## 功能模块

### 1. 全局简洁输出配置 (Concise Global)
自动应用到所有对话的简洁输出规则：
- 禁止冗长的任务总结
- 避免重复工具日志
- 自动清理临时文件
- 只在必要时提供详细输出

### 2. 简洁输出预设 (Concise Preset)
可选的简洁输出预设配置：
- 在预设列表中提供 "Concise" 选项
- 包含与全局配置相同的简洁规则
- 可以按需启用/禁用

### 3. 模型控制面板 (Model Controls)
提供模型相关的高级控制：
- 提供商暂停/启用开关
- 单模型推理强度设置
- 对话级思考模式选择器

## 安装

将此插件目录放到 DSH 的插件目录中，DSH 会自动识别并加载。

## 使用

安装后，三个功能会自动集成到 DSH 中：
- 全局简洁输出规则立即生效
- "Concise" 预设出现在预设列表
- 模型控制面板出现在设置界面

## 源组件

此插件合并了以下三个独立组件：
- `@local/dsh-concise-global` - 全局配置
- `@local/dsh-concise-preset` - 预设配置  
- `@reagent/dsh-model-controls` - 模型控制
